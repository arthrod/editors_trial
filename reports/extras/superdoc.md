# SuperDoc

## What the driver runs

`build/score_all.py` measures SuperDoc from `out/superdoc`. `build/run_all.sh` runs `harness/superdoc.mjs`. This note does not publish a new round-trip percentage for that output.

## What it is

SuperDoc is a DOCX engine aimed at the browser and at the same Document API on a server or in an agent workflow. The README says the editor is built directly on OOXML and that edits write back to the XML without an HTML conversion step.
