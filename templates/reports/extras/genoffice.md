# GenOffice

## What the driver runs

`build/score_all.py` measures GenOffice from `out/genoffice`. `build/run_all.sh` runs `harness/genoffice.cts` against the genspark-ai tree. This note does not publish a new round-trip percentage for that output.

## What it is

GenOffice describes itself as an open-source AI Office suite: Word, Excel, PowerPoint, and PDF, plus Markdown and HTML, edited in the native formats with an AI panel in the editor.

## Trivia

The license is Apache-2.0. The README opens with a language switcher that lists English and twenty-one translations. The project also documents a command-line skill and an MCP server. The site is genoffice.ai.
