# Plate.js

## What the driver runs

`build/score_all.py` measures Plate.js from `out/plate`. `build/run_all.sh` runs `harness/plate` with Bun. This note does not publish a new round-trip percentage for that output.

## What it is

Plate is a framework for building rich-text editors on the web. DOCX is a plugin path inside that framework. The harness drives the plugin. It does not stand in for the whole Plate UI kit.
